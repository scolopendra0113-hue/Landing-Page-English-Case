LinguaFlow — лендинг онлайн-школы английского
Одностраничник для школы разговорного английского с носителями. Задача — превратить холодный трафик из рекламы в заявки на бесплатный урок. Спроектировал UX-карту по AIDA, написал тексты с упором на результат и гарантию возврата, сверстал адаптив с формами захвата, маской телефона и микроразметкой Schema.org.
Роль: UX/UI + копирайт + вёрстка · Стек: HTML5, CSS3, Vanilla JS · Срок: 5 дней
